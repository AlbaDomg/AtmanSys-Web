## 📖 Overview

AtmanSys Web is a corporate website developed for AtmanSys, a software development and automation initiative focused on creating digital solutions for real-world business needs.

The project was built from scratch using HTML5, CSS3 and JavaScript, with a custom visual identity and responsive layouts designed to provide a professional experience across different devices.

The website presents AtmanSys, its services, technical capabilities and approach to software development and automation.

---

## 🎯 Objectives

The main objectives of the project were:

- Create a professional digital presence for AtmanSys.
- Communicate the company's services and technical capabilities clearly.
- Present software development and automation solutions.
- Build a custom visual identity consistent with the AtmanSys brand.
- Create a responsive experience across different screen sizes.
- Translate a technology-focused business concept into a clear and accessible website.

---

## ✨ Features

### 🎨 Custom Design

The website was designed specifically for AtmanSys rather than being based on a pre-built template.

The visual system includes:

- Custom color palette
- Typography
- Responsive layouts
- Custom components
- Visual hierarchy
- Brand-focused design

### 📱 Responsive Layout

The website adapts its layout to different screen sizes, providing a consistent experience across desktop and mobile devices.

### ⚡ Interactive Frontend

JavaScript is used to implement interactive behaviour and dynamic elements throughout the website.

### 📝 Structured Content

The project's content and messaging were organized separately in `copywriting_atmansys.md`, allowing the site's copy to be planned and maintained independently from the frontend structure.

## 🧩 Architecture

The project follows a lightweight frontend architecture based on the separation of structure, presentation and behaviour:

- **HTML5** → Semantic structure and content
- **CSS3** → Layout, responsive design and visual styling
- **JavaScript** → Interactivity and dynamic behaviour
- **Assets** → Images and visual resources
- **Markdown** → Content and copywriting documentation
